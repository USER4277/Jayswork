**docx 已探明的坑（解析器必须处理）**：

1. **每天的「三、编程作业」整段被原样复制了两遍** —— 已逐日核对，14 天的两份副本**逐行完全一致**（第 1 天 21 行、第 2 天 34 行 …）。解析时取第一份即可。切分标记：`三、编程作业` → `四、英语作业`，块内按 `^项目[一二]《` 行首表头切成两半
2. **正文用全角空格 `　`(U+3000) 和全角标点** —— `　·　`、`＝`、`÷`、`－`、`……`、`（　　数独　　）` 等，解析时要 NFKC 归一化后再比对
3. **数独/图形题用表格承载**，空单元格是空字符串（= 待填格），数字是题目给定值；答案区同样是表格

5. **题号在行首**：`1.`–`10.` 紧跟题目文本；`（一）`–`（五）` 是 5 个类别的分隔行
6. 表格单元格里用 `||` 分列、`/` 分隔多段落（python-docx 的 `tr.cells` 天然给出列，段落需自行 join）
7. 文档中还有 `签名栏`、目录、`编程项目总览`、项目规则、`自查清单`、`英语句型速查表`、`给家长的话` 等区块 —— 分别切片进 `projects` / `checklists` / `meta` 字段

**答案形态（answerFormat）枚举**，后端按形态分派判分器：

| 形态 | 输入控件 | 判分器 |
|---|---|---|
| `number` | 一个数字框 | 数值相等（归一化后） |
| `numbers` | N 个带标签的数字框 | 每个分别比 |
| `grid` | N×M 可填格子 | 数独规则校验，指出冲突位置 |
| `expressions` | N 个算式输入框 | 表达式求值 + 数字多重集校验 |
| `ranking` | N 个有序下拉 | 序列完全一致 |
| `choice` | N 个下拉（圆/三角/方形、能/不能） | 取值一致 |
| `lines` | N 行结构化输入 | 逐行规则校验（采购员） |
| `text` | 大文本框 | **AI** |
| `text+number` | 大文本框 + 数字框 | 数字自动 + 文本 AI |

**24 点自动验算**：把学生的算式解析成 AST（只允许 `+ - × ÷ * / ( )` 和数字），用**有理数精确运算**（BigInt 分子/分母，避免浮点误差）求值，再校验结果 = 24 且用到的数字多重集恰好等于给定 4 个数、每个用一次。第 2 个算式还要去重检查是否为「两种不同的算式」（docx 答案区本身也标注了「(5 − 3) × 4 × …… 不必举反例」）。

**数独自动校验**：docx 表格结构可直接解析 —— 空字符串 = 待填格，数字 = 题目给定值；答案区同样是 4×4 / 6×6 矩阵。规则随题号确定：4×4 每行/列/2×2 宫填 1–4，6×6 每行/列/2 行 3 列宫填 1–6。判分时逐格校验，错时精确指出「第 3 行第 2 列与第 3 列数字重复」这类具体位置。docx 的 5 个答案网格已核对一致（4 个 4×4 + 2 个 6×6 均为合法解；第 12 天是 4×4）。

**答案归一化**（`grading.js`）：Unicode NFKC（全角→半角，`＝`→`=`，`…`→`...`，`－`→`-`）→ 去空白 → 提取数字（支持 `8余3`、`8……3`、`12……2` 这类内联写法）→ 数值比较。docx 里 `＝` 与 ASCII `=` 混用、`−`(U+2212) 与 `－`(U+FF0D) 混用、`……` 前后空格时有时无，都必须归一化后再比。

**图形题渲染**：

- 5 个数独图（day 1/3/5/10/12）→ 可填写的 N×N 格子，按 2×2 / 2×3 宫画粗边框
- day 9「数图形」的 3×3 全空图 → 画成 3×3 带横竖线的正方形（3×3 是 9 个小格，题意是「每边三等分」）
- day 12「一笔画」的图**不是表格而是 1 列 7 行的 ASCII 画**（`●─────────●` / `│╲ ╱│` …），用等宽字体 `<pre>` 原样渲染，不能当作数独网格解析
- `（　　数独　　）` 是装饰性 caption，解析时丢弃

**英语听力选择题**：docx 只有对话，没有选择题。build 脚本为每天从当日对话行中生成「听→选」题（正确句 + 3 个同日干扰项），并挑 2–3 句做「跟读」句。生成后人工复核一遍，固化进 homework.json（家长可在后台改）。

**语音方案**（`lib/speech.ts`，全部用浏览器原生能力，零成本、离线可用）：

- **朗读**：`SpeechSynthesis` — 中文讲解用 `zh-CN`，英文句子用 `en-US`（macOS 自带音色）
- **语文语音作答**：`webkitSpeechRecognition`，`lang=zh-CN`；Safari 不支持时自动降级为纯输入并提示
- **英语跟读**：`MediaRecorder` 录音 → 回放 → 波形/时长显示；可选接 MiniMax ASR 做转写后 AI 打相似度分（env 开关 `ENABLE_SPEECH_SCORING`）

**四类作业页交互**：

- **数学**：按 5 类分组渲染，每题独立作答区（余数题两个输入框、数独题可填网格、应用题「答案 + 过程」两栏）。提交后 → 逐题判定 → 对错卡片 + 语音朗读讲解 + 「再试一次」订正流 → 错题自动进错题本
- **语文**：阅读片段（可朗读）→ 3 问，每问「文字输入 / 语音输入」双通道 → 提交 → AI 逐问批改（判定 + 讲解 + 订正建议）
- **英语**：三个板块 — ① 听→跟读（录音回放）② 听→选择（TTS 播题，4 选 1，自动判分）③ 对话（挖空补全 / 角色朗读）
- **编程**：今日目标 → 先读一读 → 今天这样做（步骤清单）→ 「可以复制给 AI 的话」（一键复制 + 显示全文）→ 保存小抄（如有）→ 怎么知道自己做对了 → 今天的收获（文本，存 DB）→ 今天我学到的一件事 → 项目自查清单（可勾选，持久化）

## 4. 学习监控：语音播报 + 摄像头 + 画面实时同步到爸爸手机

孩子每天在首页点「开始今日作业」时触发这一整套流程：

1. **语音播报**（`SpeechSynthesis`，zh-CN，语速偏慢）逐字念出：
   > 「现在开始做作业，实时监控已打开，请认真完成作业，画面实时同步到爸爸手机。」
   同时在页面上以大字卡片显示同一句话（可静音重播），确保孩子看得见也听得见
2. **立刻调用系统摄像头**：`navigator.mediaDevices.getUserMedia({video, audio:false})` —— 必须在点击事件的同步调用栈里发起，否则 Chrome 不会弹授权框
3. **打开录像功能**：`MediaRecorder` 持续录制，分片实时上传到本地服务器落盘
4. **显示器右上角展示实时图像**：固定位置的画中画（PiP）浮层，画面可拖动、可缩放、可临时隐藏（隐藏时仍在录像）
5. **画面实时同步到爸爸手机**：孩子的浏览器把缩放后的 JPEG 帧经 WebSocket 推到本地服务器，服务器转发给爸爸手机上打开的观看页

**技术选型与约束**：

| 项 | 方案 | 说明 |
|---|---|---|
| 摄像头 | `getUserMedia` | 需要**安全上下文**：孩子端必须走 `http://localhost:4000` 或 HTTPS。用局域网 IP（`http://192.168.x.x:4000`）访问时浏览器会禁用摄像头 —— 因此**孩子用本机 localhost，爸爸手机用局域网 IP 访问观看页**即可（观看端不需要摄像头，不受此限制） |
| 实时同步 | **WebSocket 帧中转**（非 WebRTC） | 孩子端 `canvas` 缩放到 320×240 → `toBlob('image/jpeg', 0.5)` → WebSocket 上传；服务端按 `sessionId` 转发给所有观看者。理由：同一局域网内无需 STUN/TURN/打洞，零外部依赖，手机浏览器打开网页即可看。带宽约 3 fps × ~15 KB ≈ 45 KB/s，家用 Wi‑Fi 无压力 |
| 帧率控制 | **仅在有观看者在线时才推流** | 没有观看连接时停止发送帧，节省带宽；录像不受影响 |
| 录像 | `MediaRecorder` → 分片上传 → 服务端合并落盘 | 存 `server/data/recordings/<日期>/<sessionId>.webm`，家长区可回放/下载 |
| 语音 | `SpeechSynthesis` | 浏览器原生、离线、零成本；首次需用户手势，正好在点击处理器里 |

**安全与隐私**（实现时必须做到）：

- 画面**只在本机局域网内转发**，不经过任何外部服务；MiniMax API 只收到文字（作业内容），不会收到图像
- 监控开关在家长区可关；关闭后前端不再申请摄像头权限
- 观看页需要家长 PIN 才能打开，避免孩子自己关掉监控
- 页面常驻一个明显的「监控进行中」指示灯，摄像头浮层不可完全消失（最小化为一个小红点图标即可）

**新增文件**：

```

server/src/ws.js               WebSocket 服务（升级握手、房间管理）
web/src/pages/WatchPage.tsx    爸爸手机的观看页（/watch）
web/src/components/CameraPiP.tsx  摄像头浮层 + 录像 + 帧推送
web/src/lib/camera.ts          getUserMedia / MediaRecorder / 帧压缩推送
web/src/lib/announce.ts        语音播报封装
