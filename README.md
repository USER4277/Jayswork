# 曹昌洵专属教育系统

给曹昌洵一个人用的每日作业系统 + 学习中心。作业内容全部来自
《小学 14 天作业本_数学语文英语编程》，本机运行，内容不出家门。

---

## 快速开始

```bash
# 1. 装依赖
npm install

# 2. 生成作业内容（第一次必须做；内容更新后重跑）
npm run content

# 3. 配置 AI（可选，但强烈建议配，开放题要它批改）
cp .env.example .env
#   然后把 MINIMAX_API_KEY 填上

# 4. 起服务
npm start           # 打开 http://localhost:4000
```

开发的时候用 `npm run dev`（前端 :5173 + 后端 :4000，前端代理 /api）。

> **必须用 `localhost` 打开。** 浏览器只在「安全上下文」里允许调用摄像头，
> 用局域网 IP（`http://192.168.x.x:4000`）打开的话摄像头会被浏览器禁用。

## 每天怎么用

1. 打开首页，点 **「开始今日作业」**
2. 会听到语音播报「现在开始做作业，实时监控已打开……」，右上角出现实时画面
3. 按顺序做 **数学 → 语文或英语 → 编程**
4. 每科做完点「提交批改」，系统逐题批改，错的会给出讲解并能朗读
5. 做错的题自动进 **错题本**（按科目 + 7 天一个周期整理）

## 排期

作业锚点是 **2026-10-26**（作业本第 1 天），一共 28 天：

| 日期 | 数学 | 语言 | 编程 |
|---|---|---|---|
| 10/26 – 11/08（第 1–14 天） | ✅ | 语文/英语隔天 | ✅ |
| 11/09 – 11/22（第 15–28 天） | 待补充 | 语文/英语隔天 | 待补充 |

语文和英语按日序奇偶交替，14 篇语文 + 14 段英语正好在 28 天里用完。
未来的日期打不开（锁着），只能看当天的和以前的。

往后要加内容：在 `作业/homework.json` 里补上第 15 天以后的数学和编程，
再把 `开发/content/build_content.py` 里的切分逻辑放宽即可，代码不用动。

## 各项功能在哪

| 功能 | 说明 |
|---|---|
| 数学 | 5 类题型各自适配的作答区；四则运算/加减/余数/数独/24 点都能精确自动判分 |
| 语文 | 阅读片段可朗读；3 问支持打字或语音作答；AI 逐问批改 |
| 英语 | 听→跟读录音、听→选择、对话补全；朗读和录音都用浏览器原生能力 |
| 编程 | 今天的引导 + 一键复制给 AI 的话 + 自查清单 + 收获记录 |
| 错题本 | 按科目分组，组内按 7 天一个周期分段 |
| 学习中心 | 知识点图谱（242 个小学数学知识点）、AI 答疑、练习、复习计划 |
| 学习报告 | 完成率、正确率、按周统计；家长区还有 AI 写的每周小结 |
| 学习监控 | 开始作业时播报 + 打开摄像头 + 录像 + 同步到爸爸手机 |

## 爸爸手机看画面

需要两步：

1. 在 `.env` 里把 `HOST` 改成 `0.0.0.0`，重启服务
2. 手机浏览器打开 `http://<电脑局域网IP>:4000/watch`，输入家长 PIN（默认 `0000`）

画面只在家里这台设备和手机之间直接传递，不经过任何外部服务，也不写进任何云。
用完建议把 `HOST` 改回 `127.0.0.1`。

---

## AI 没配 key 会怎样

- 数学的数值题、数独、24 点 —— 不受影响，照样精确判分
- 语文的 3 问、应用题的过程、开放题 —— 会显示「等 AI 老师批改」
- 学习中心的答疑 —— 会提示 AI 未连接

配好 key 之后重启服务即可，不用重新生成内容。

## 常见问题

**页面显示「没有安排作业」**
今天是 2026-10-25，作业从 2026-10-26 开始。想先看看，可以在 `.env` 里设
`PREVIEW=1` 打开试看模式（会解除未来日期的锁）。

**摄像头开不了**
浏览器只允许在 `localhost` 或 HTTPS 下用摄像头；另外要允许浏览器使用摄像头权限。

**想改作业内容**
改 `开发/content/build_content.py` 里的解析规则，重跑 `npm run content`，
重启服务即可生效。家长区里改 PIN、截止时间等设置不需要重新生成内容。
