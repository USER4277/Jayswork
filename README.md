# 曹昌洵专属教育系统

每日作业、自动批改、错题复习、三科知识图谱和家长管理。本机运行，数学、语文和编程来自《小学 14 天作业本_数学语文英语编程》，英语使用本地 RAZ 分级资源；知识点来自同级目录的 `cn-math-taxonomy`。启用 AI 时相关作业文字会发送给模型服务，RAZ 听读和判分不需要 AI。

---

## 快速开始

```bash
# 需要 Node.js 22.13+（建议 22.22+）、npm 及 FFmpeg/ffprobe（音频时长分析）
npm install
# 可选：在本机编辑 .env 配置 MiniMax，不要提交或分享密钥
cp .env.example .env
npm run build
npm start
```

打开 http://localhost:4000。已包含生成后的作业和图谱 JSON，首次启动不需要运行内容管线。后端配置或内容更新后需要重启服务。

RAZ 默认目录为 `~/Documents/English/RAZ全套资源`。目录不同时，在启动环境中设置 `RAZ_RESOURCE_DIR` 为绝对路径。原始资源只读，不复制到代码或学习数据库；家长区可重新扫描目录。首次使用英语时先测级，也可由家长指定起点。

开发用 `npm run dev`（前端 :5173，后端 :4000，前端代理 `/api`）。正式启动前须 `npm run build`。macOS 新安装的数据默认保存在 `~/Library/Application Support/Jayswork/data`，与代码目录分离；已有 `preview/app.db` 时继续使用同级 `preview` 目录，避免切到空库。`DATA_DIR` 可显式指定位置。发现旧 `server/data/app.db` 时会要求先备份并明确指定目录，不会默默新建空库。

已有数据库每次启动时，在迁移前通过 SQLite `VACUUM INTO` 生成一致性快照到数据目录的 `backups/`，包含 WAL 中的已提交数据。快照只包含数据库，不包含录音和录像；完整备份应在结束录像、停止服务后，将整个数据目录复制到外部备份位置。不要单独复制运行中的 `app.db`。请定期管理备份容量。

> **必须用 `localhost` 打开。** 浏览器只在「安全上下文」里允许调用摄像头，
> 用局域网 IP（`http://192.168.x.x:4000`）打开的话摄像头会被浏览器禁用。

## 每天怎么用

1. 打开首页，点 **「开始今日作业」**
2. 家长启用录像时，会播报摄像头提示，并在右上角显示本机实时画面；需要允许摄像头权限
3. 按顺序做 **数学 → 语文或英语 → 编程**
4. 数学、语文做完点「提交批改」，系统逐题反馈；英语完成当天听读、理解和表达后点「完成今日英语」
	数学只在点击提交后显示批改和解答；错题修改后逐题点「提交订正」，不重复批改其他题目。
5. 做错的题自动进 **错题本**（按科目 + 7 天一个周期整理）
6. 编程只列当天目标、功能和可玩里程碑，不提供实现步骤，不要求写心得；试玩通过后确认完成。每个项目完成 7 天后开放参考游戏，也可由家长提前解锁
7. 录像结束时点击画面上的结束按钮，等待保存完成后再关闭页面

数学、语文草稿保存在当前浏览器，提交后的答案和批改结果保存在本机数据库。数学重新进入页面时恢复答案，但不自动显示历史批改。数学题目没有朗读按钮，提交后的讲解可朗读；四则运算提供运算顺序与中间结果，万以内加减法提供对齐竖式及进借位，28 道应用题提供本地思路、列式依据、单位和答句。应用题原始参考中的牛奶倒推题和花坛题已分别纠正为144盒和46个。错题复习由服务端重新判分，按 1、2、4、7、15 天间隔安排。

英语改为独立的 RAZ 课程。首次用 AA、A、C、G 的代表绘本逐级测定起点；家长可调整级别和每次目标时长（10–40 分钟，默认 20 分钟）。每天依次进行到期复习、原声听读、绘本阅读、理解练习和简短表达。桌面以绘本为主阅读区，侧栏放原版音频和进度；窄屏音频移到绘本上方。可配对的教师讲解和视频折叠显示，不展示教师答案或资源文件列表。

阅读页支持翻页、页码和缩放；默认整页适配视窗。长书按字数与原版音频时长分次安排，同一天的任务固定，未完成任务下次继续。长书的页码和音频按比例分段，不是逐句或逐页精确同步。进度、选择题草稿和表达会保存；最后需听完本段、读到本段末页、提交理解题，并保存至少两字表达或一段录音。低分仍可完成当天任务，首次理解成绩与完成状态分别保存，订正不覆盖首次表现。表达录音仅存本机，不进行 ASR 或专业发音评测。

读完一本后按 1、3、7、14 天安排复习，在后续英语日呈现；同书多次逾期合并，不重复挤占当天任务。通常每第五次完成课次可安排复习课。当前级别至少完成 8 本有分数的书、首次平均正确率达到 80%，且至少两个不同日期的延迟复习平均达到 80%，才建议家长确认升级。资源用完后进入复习，不自动跳级。

当前目录可索引 AA 至 Z2 共 29 个级别，约 2,414 个候选书目，其中约 2,394 个可按标题配对原版音频；这不是逐本人工核验结果。可可靠解析的原版选择题在服务端判分；低级别可从实际绘本文字生成词义题。扫描版或无法可靠解析的测验不编造答案，改用未自动评分的表达任务。资源更新后数量可能变化，以家长区扫描结果为准。

界面默认夜间模式，可切换日间模式并记住选择；使用儿童尺寸文字、按钮和输入区。

开始作业必须点击首页「开始今日作业」按钮，科目卡片仅展示安排和进度。按钮按「数学、当天语言课、编程」顺序进入第一个未完成的科目，跳过已完成的作业。全部完成后，点击只播报并显示「今日作业已全部完成，请立即离开。」，不再进入作业或开启摄像头。当前标签页当天未开始时，直接打开作业地址也会返回首页；开始后刷新或继续下一科不受影响。错题本仍可正常进入。

当天所有安排的作业均完成后，正在进行的摄像头录像会自动停止，等待最后一段上传保存完毕后释放摄像头并关闭预览；只完成一科、数学尚未订正或提交失败时不会提前停止。检查完成状态失败时继续录像并提示手动结束保存。

当天数学有安排时，只有每题全部答对、没有待核对内容，才能进入语文；全部答对后自动跳转，并播报「下面开始今日的语文作业」。英语日仍按原排期进入英语。没有数学安排的后 14 天不受这项前置条件限制。数学应用题只按数字答案判定对错和成绩，想法与计算过程不影响通过；AI讲解仍显示，过程有误或部分正确仍记入错题本，但不阻止进入下一科。过程未填写或AI暂不可用时，数字答案正确也可通过。

语文全部按开放作答题处理，没有要求逐字一致的唯一答案。提交后，每题出现「解答」按钮，点击展开参考思路与讲解。语音回答同时保存原始录音和识别文字，可在题目下回放或下载，刷新后仍保留；录音上传失败时须先重试保存，再提交作答。

## 排期

作业锚点是 **2026-10-26**（作业本第 1 天），英语不受原作业本的 28 天范围限制：

| 日期 | 数学 | 语言 | 编程 |
|---|---|---|---|
| 10/26 – 11/08（第 1–14 天） | ✅ | 语文/英语隔天 | ✅ |
| 11/09 – 11/22（第 15–28 天） | 待补充 | 语文/英语隔天 | 待补充 |
| 11/23 起 | 待补充 | 英语持续隔天；语文待补充 | 待补充 |

语文和英语按日序奇偶交替；语文现有 14 篇，英语由日期决定是否上课、学习进度决定读哪本书。首页显示从当天起未来 28 天安排。
只允许打开、填写和提交当天作业，不能切换到过去或未来日期；首页日历仅显示排期。`PREVIEW=1` 也不能绕过日期限制。

第 15 天起没有现成数学和编程题目，语文资源用完后也不会重复安排。追加这些内容需要更新内容管线，并相应扩展排期和测试；英语无需为后续日期追加作业本条目。

## 家长与隐私

家长区默认 PIN 为 `0000`，首次使用应修改。家长设置、答案、每周 AI 小结和录像回放均需要登录；退出登录会撤销会话。

### 英语测试

进入「家长」并验证 PIN，打开「英语测试」。可查看资源扫描结果、调整正式课程级别与目标时长，或为独立测试选择英语日期和起点。过去和未来的英语日均可测试，不限于旧的 14 个日期；无需修改电脑时间，也不解除正式作业的当天限制。

测试与正式作业共用 RAZ 页面和判分逻辑，测试数据库和表达录音单独保存在数据目录的 `tests/english/`，不计入正式成绩、错题、报告或录像会话。RAZ 测试不调用 MiniMax；题目朗读使用浏览器语音服务，是否离线取决于设备提供的语音。

点击「返回家长区」退出测试；「重置测试」清除独立 RAZ 测试课程的测级、排课与学习记录，不改变正式课程，已保存录音文件不会因此自动删除。家长退出或会话过期后，测试接口、绘本和录音均不可访问。正常作业始终只允许当天作答。

- 摄像头只用于本机预览和录像，不录制音频、不上传云端，也不会假称有人远程观看。原 `/watch` 地址改为跳转家长区。
- 默认仅监听 `127.0.0.1`，不应直接向公网开放儿童作业和录像。
- 启用 MiniMax 后，批改、答疑和周报所需的作业文字会发送给配置的模型服务；密钥只由后端使用。
- RAZ 表达录音保存在本机数据目录的 `voice/`，不发送给 MiniMax。旧版英语录音与接口保留兼容；旧接口仍可能使用 MiniMax ASR 和文字评分，但不参与新的 RAZ 页面。
- 语文语音回答会保存到本机数据目录的 `voice/`，识别文字保存在数据库。内置浏览器若不支持播放格式，可下载后播放，或使用 Chrome、Edge。真实麦克风与语音服务需在目标设备验收。
- 朗读和语音输入取决于浏览器支持；浏览器语音识别可能使用其厂商的在线服务，不可用时仍可打字作答。
- 截止时间是提醒，不强制关闭作答。关闭录像开关会停止当前录像并保存；录制期间请保持服务运行。

录像与数据库都在数据目录，需要定期备份和清理。浏览器崩溃、断电或强制关闭页面时，不保证最后一段录像完整。

## 内容更新

只有更新原始作业或知识图谱时才需要 Python 管线：

```bash
python3 -m pip install -r 开发/content/requirements.txt
npm run content
# 或只刷新三科图谱
python3 开发/content/build_graph.py --src ../cn-math-taxonomy
```

作业源文件默认位于 `作业/`。图谱优先读取同级源仓库；源仓库不存在且未显式指定 `--src` 时，保留已打包的图谱数据。

人工整理的语文参考思路保存在 `作业/chinese_answers.json`，共 14 篇、42 题；简化拓展题保存在 `作业/math_extensions_easy.json`，共 14 天、28 题；应用题详细讲解在 `作业/math_word_solutions.json`；开放式编程里程碑在 `作业/coding_milestones.json`。加载作业时合并这些文件，重新生成原始作业 JSON 不会覆盖它们。

## MiniMax 接入

以[官方接口总览](https://platform.minimax.cn/docs/api-reference/api-overview)、[OpenAI兼容接口](https://platform.minimax.cn/docs/api-reference/text-openai-api)及[ASR接口](https://platform.minimax.cn/docs/api-reference/speech-to-text)为准。

- 文本批改、答疑和周报：`POST {MINIMAX_BASE_URL}/chat/completions`，使用 `MINIMAX_MODEL`、`max_completion_tokens`、`reasoning_split: true`。M3显式发送 `thinking.type: disabled`，Flash使用 `adaptive`；不向M3发送无效的温度调节参数。
- 结构化批改使用JSON格式并容忍思考标签、代码围栏；格式错误重试一次。请求有超时，失败不自动通过。
- 旧版英语识别接口（新 RAZ 页面不调用）：`POST {MINIMAX_SPEECH_BASE_URL}/speech_to_text`，默认沿用 `MINIMAX_BASE_URL`；使用 `model=asr-1.0`、multipart文件和 `language: en`。没有独立密钥字段，使用同一后端密钥；语音接口权限和额度以账户实际情况为准。
- 密钥只配置在本机 `.env` 的 `MINIMAX_API_KEY`，不提交到仓库，不传给前端。M3当前不支持音频输入，不能直接把录音放进聊天消息冒充音频评测。

## AI 没配 key 会怎样

- 数学的数值题、数独、24 点 —— 不受影响，照样精确判分
- 语文全部 42 道题有本地参考思路和讲解：未配置 AI 或请求失败时，提交后可逐题点「解答」查看；不靠字符串匹配给开放题判分
- 数学应用题按数字答案判断通过，AI过程评价只作展示与错题复习，不影响进入下一科；其他需AI判定的开放题仍需完成核对
- 学习中心的答疑 —— 会提示 AI 未连接
- RAZ 原版音频、绘本阅读、选择题判分及表达保存不受影响，不需要 AI 密钥

配好 key 之后重启服务即可，不用重新生成内容。

## 常见问题

**页面显示「没有安排作业」**
作业从 2026-10-26 开始，只能填写当天安排的内容；开始前首页仍可查看排期。`PREVIEW` 不解除日期限制。

**摄像头开不了**
浏览器只允许在 `localhost` 或 HTTPS 下用摄像头；另外要允许浏览器使用摄像头权限。

**想改作业内容**
改 `开发/content/build_content.py` 里的解析规则，重跑 `npm run content`，
重启服务即可生效。家长区里改 PIN、截止时间等设置不需要重新生成内容。
