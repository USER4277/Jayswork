## 一、《星星捕手》玩法

小猫 🐱 站在地上，天上会掉下来两种东西：

- ⭐ **星星**：接住 +1 分
- 💣 **炸弹**：接住 −1 颗心，还会被炸得闪一下（1.2 秒无敌，趁机躲一下）

一开始 3 颗心，一局 60 秒。**连着接到 5 颗星星**就会亮起「连击 ×2」，接下来一颗星星算 2 分。

**按键**：`←` `→` 或者 `A` `D`（按住不放，小猫会一直跑）

## 二、《太空采矿记》玩法

飞船 🚀 在太空里飞，屏幕最下面是**基地 🏠**。

- 🪨 普通矿石 1 分，💎 金色矿石 3 分（金色的少一些）
- 矿石要**飞回基地交货**才真正算分，光捡到不算
- 货舱最多装 **6 块**，装满了就采不了了
- ☄️ 陨石越掉越快，撞到扣 1 条命
- ⛽ 燃料会一直减少，采到矿石能补，**燃料用完游戏就结束**
- 时间越久越难：第 1 关、第 2 关……陨石越来越多、越来越快

**按键**：`W` `A` `S` `D` 或者 方向键

## 四、几个关键做法（用小学生能懂的话讲）

### 1️⃣ 星星和炸弹，其实是"同一样东西"

你可能会以为要写两堆代码，其实在《星星捕手》里**只写了一个方块**：

```js
// 下落物生成器：kind 决定它是星星还是炸弹
function spawnFalling(kind) {
  const isStar = kind === 'star';
  state.falling.push({
    kind: kind,
    x: rand(26, W - 26),          // 随机位置
    y: -size,                    // 从画面外面进来
    vy: isStar ? STAR_FALL : BOMB_FALL,   // ← 只改了几个数字
    size: isStar ? STAR_SIZE : BOMB_SIZE,
    ...
  });
}
```

**差别只有 3 个**：掉多快（`vy`）、画多大（`size`）、画什么表情（`⭐` 还是 `💣`）。
所以"让炸弹比星星快一点、出现得少一点"，就是改两个数字而已。
你如果想加第三种东西（比如 🛸 飞船残骸），照着抄一份、改三个数字就行。

### 2️⃣ 什么叫"逻辑分辨率 480×640"？

我们先在纸上画好一张 **480 宽 × 640 高** 的画，代码里的所有位置都按这张纸来算。
浏览器窗口大，就把这张画**整体放大**；窗口小，就整体缩小。
所以**每台电脑、每个手机窗口大小都不一样，但玩起来的手感完全一样**，不会在别人电脑上飞得特别快。

### 3️⃣ 为什么要用"时间"而不是"每帧"来算速度？

如果写成"每刷新一次就往前挪 5 格"，那 60 帧的电脑和 144 帧的电脑速度就差一倍多。
我们写的是"**1 秒钟跑 330 格**"：

```js
const dt = Math.min(0.05, (now - last) / 1000);  // 距离上一帧过了多少秒
state.catX += dir * CAT_SPEED * dt;               // 330 × 过了多少秒
```

`dt` 就是"距离上一帧过了多少秒"。不管电脑一秒刷 60 次还是 144 次，乘出来都一样。
`Math.min(0.05, ...)` 是"保险丝"：万一电脑卡了一下，`dt` 不会变得太大把东西甩出画面。

### 4️⃣ 碰撞检测就是"两个方块有没有重叠"

小猫是一个方块，星星也是一个方块。用 `>` 和 `<` 一比，就知道有没有撞上：

```js
if (hitR > catL && hitL < catR && hitB > catT && hitT < catB) {
  // 撞上了！
}
```

而且我们给碰撞框**故意画得比看到的图案小一点**，这样孩子会觉得"明明差一点就接到了"，而不是"明明没碰到却扣血了"。

### 5️⃣ "无敌时间"是怎么实现的？

被炸弹炸到以后，把 `invincible` 设成 1.2 秒，每帧减一点：

```js
if (state.invincible > 0) { /* 碰到炸弹就弹开，不扣心 */ }
```

同时画小猫的时候让它的**透明度一闪一闪**，孩子一眼就知道"我现在是不怕的"。

### 6️⃣ 分数为什么要"回基地"才算？

《太空采矿记》里，矿石只是"**进货舱**"，HUD 里的货舱格子会亮起来，但分数**不动**。
等飞船飞到底下碰到基地，才 `state.score += 货舱里所有矿石的分`。
这样才有"出去干活、回家交货"的成就感，也让孩子理解"目标和奖励是两回事"。

### 7️⃣ 最高分是怎么记住的？

`localStorage` 可以理解成"浏览器自带的存钱罐"：

```js
localStorage.setItem('homework-star-best', '99');   // 存进去
localStorage.getItem('homework-star-best');          // 读出来
```

关掉网页、第二天再打开，分数还在。
《太空采矿记》的**前 5 名排行榜**也是这么存的（存成一小段文字：`[{"name":"小矿工","score":120}, ...]`）。

> 小提醒：有的浏览器打开"本地文件"时不让用存钱罐。所以参考版在外面包了一层 `try...catch`，
> 万一不让用，游戏照常玩，只是关掉网页后记录会丢。**这一点你的版本也可以试试加**，会更稳。

### 8️⃣ 音效是"当场算"出来的，没用音频文件

```js
const osc = audioCtx.createOscillator();   // 一个"会发声的振荡器"
osc.frequency.setValueAtTime(880, t);      // 从 880 赫兹开始
osc.frequency.exponentialRampToValueAtTime(1320, t + dur);  // 滑到 1320
```

接星星是"叮"的一声上扬，被炸是"嗡"的一声下滑。
**没有一个 .mp3 文件**，所以完全不需要联网。
